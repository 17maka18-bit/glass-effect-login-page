# Glass Effect Login Page

##  პროექტის აღწერა

Glass Effect Login Page არის ავტორიზაციის გვერდი, რომელიც შექმნილია HTML5-ისა და CSS3-ის გამოყენებით, Figma-ს დიზაინის მიხედვით.

პროექტის მთავარი მიზანია თანამედროვე ვებგვერდის დიზაინის შექმნა, Glassmorphism ეფექტის გამოყენება და HTML/CSS-ის პრაქტიკული ცოდნის გაღრმავება.

##  დიზაინი და ფუნქციები

- ლურჯი გრადიენტული ფონი
- გამჭვირვალე ავტორიზაციის ბარათი (Glassmorphism)
- Background Blur ეფექტი
- Figma-დან გადმოტანილი 3D დეკორატიული ფორმები
- Email და Password ველები
- Forgot Password ბმული
- Sign In ღილაკი
- სოციალური ქსელების ღილაკები: Google, GitHub და Facebook
- Hover და Focus ეფექტები
- ადაპტური დიზაინი (Responsive Design)

##  გამოყენებული ტექნოლოგიები

- **HTML5** — ვებგვერდის სტრუქტურის შესაქმნელად
- **CSS3** — დიზაინისა და ვიზუალური ეფექტებისთვის
- **Flexbox** — ელემენტების განლაგებისთვის
- **CSS Gradients** — ფონის ფერებისთვის
- **Backdrop Filter** — მინის ეფექტის შესაქმნელად
- **Media Queries** — სხვადასხვა ეკრანის ზომასთან ადაპტაციისთვის
